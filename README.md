# InvoiceFlow für Windows

Den aktuellen Installer findest du unter [Releases](https://github.com/wreckedangler/InvoiceFlowApp-releases/releases/latest).

Die Setup-EXE installiert InvoiceFlow unter Windows 10/11 (64 Bit). Node.js und Git werden nicht benötigt. Installierte Versionen prüfen beim Start automatisch auf Updates.

Rechnungen und Kundendaten bleiben lokal auf dem jeweiligen Rechner. Dieses Repository enthält nur Installer und Update-Metadaten.
